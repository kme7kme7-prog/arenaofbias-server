# 2026-10-05 · 有票作品下架与作废对局 · wsnxxxs

- 负责人：wsnxxxs ｜ 执行 AI：Claude Opus 5.5（Claude Code 桌面版）。范围为后端作品删除、计票规则与管理页文案；配套 Gallery 改动见 Gallery 仓库同名归档。用户授权提交与推送，未授权部署。

## 本轮目标

用户询问有对局记录的作品如何下架删除，确认方案：拆分下架、作废、清除三种处理，并接受排行变动。

## 改动

- `DELETE /api/works/:task/:id` 不再对有票作品返回409。默认下架为软删除，作品退出展厅与盲评池，已有票继续计入；有票投稿保留托管文件，无票投稿照旧删除文件。
- 可选请求体 `void` + `reason`：普通与高级管理员，原因必填，作品转 `questioned`（数据包作品写覆盖层状态），相关票退出排行。`purge`：仅高级管理员，清除投稿托管文件。两者可对已下架作品再调用；审计 `delete` / `delete-followup`。
- 计票由 `isEligible` 改为 `library.ballotWork` + `countsVotes`：要求 verified、内容放行、生成方式合格，不再要求 `show_arena` 或未下架。匹配池、投票时 `changed` 判定、内容服务仍用 `isEligible`。
- api-contract、README、`admin/admin.js` 删除文案同步为下架。无迁移，仍v40。

## 决策

- 下架不改写历史：作者删除输掉的作品不能再抹掉对手的胜场。只有比较本身无效（冒名、作弊、生成方式不实）才作废对局，由管理员写原因。
- 用户接受上线后的排行变动：此前因关闭盲评开关、或旧规则前已删除而被剔除的票会重新计入。
