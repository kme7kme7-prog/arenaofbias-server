## 改动

- 在 `server/db.mjs` 末尾追加幂等 v18，已存在迁移不改写。删除 `works.audience`、`tool`、`vendor`、`reviewed_by`、`deleted_by` 和 `votes.identity_source`，移除 `works_audience` 索引。本机 Node SQLite 已验证可直接删除带自身 CHECK 的 audience 列，无需重建整表。

- 没有 Harness 且「其他」为空的旧 tool 回填 `harness_other`。投稿兼容旧 tool 输入，公开视图、管理员视图、收录导出的 tool/audience 都从保留字段派生。有非空 Harness 声明时以其为准。
- 缺少对应审核/删除审计的旧操作人补入 audit；用最近审核记录解析审核人，添加对应部分索引。新审核和删除的状态及审计同事务写入。Show1 兼容层读取模型字典，导入脚本适配新列，旧源库 model_name 读取保持不变。
- 历史 votes.source、原始身份、更正值、matches 数据包绑定不改动；通过显式数据包快照读作品时仍使用绑定字典。同步接口契约、Show1 迁移文档和 HANDOFF。
