# 普通管理员批量上传工具包

这是修过安全问题后的独立包。功能需服务端已开 `BATCH_UPLOAD=1`。默认关闭时不要对 `https://api.arenaofbias.icu` 运行 `auth`、`upload`、`status` 或 `cancel`。

## 目录

- `tools/batch-upload/` — 上传小工具。入口是 `aob-batch.mjs`。摘要算法在同目录的 `plan.mjs`，不依赖仓库里的其他文件。
- `docs/batch-upload.md` — 完整操作与安全说明
- `skill/SKILL.md` — 给 AI 用的说明（装进 Cursor 或同类工具即可）

运行时会 import 的文件都在 `tools/batch-upload/`：`aob-batch.mjs`、`plan.mjs`、`walk.mjs`、`credentials.mjs`、`http.mjs`、`zip.mjs`、`limits.mjs`、`json.mjs`。

## 本机准备

1. 安装 Node.js 22.13 或更新。`zip.mjs` 需要 `zlib.crc32`（Node.js 22.2.0 起提供）。Linux 还需 `secret-tool`（没有就不能 `auth` / `upload` / `status` / `cancel`）。
2. 选定一个允许根目录，把**绝对路径**写入 `~/.config/arenaofbias/batch-root`（普通文件，不要用符号链接，不要用家目录）。
3. 在允许根下准备批次目录：每个作品一个子目录，入口 `index.html`；写好 `manifest.json`。不要放密钥、`.env`、符号链接或硬链接。

## 命令（在本工具包根目录执行）

```text
node tools/batch-upload/aob-batch.mjs plan --dir <允许根内的批次目录>
node tools/batch-upload/aob-batch.mjs auth --dir <同一目录>
node tools/batch-upload/aob-batch.mjs upload --dir <同一目录>
node tools/batch-upload/aob-batch.mjs status --dir <同一目录>
node tools/batch-upload/aob-batch.mjs cancel --dir <同一目录>
```

`plan` 不联网。本地限额是每批 10 件、压缩 100 MiB、解压 300 MiB，单件还有 30 MiB / 150 MiB 上限。`status` 和 `cancel` 只读 `plan.json`，作品被移走后仍可查询或取消。`auth` 和 `upload` 只连 `https://api.arenaofbias.icu`。

令牌和设备码进操作系统凭据库，不进命令参数。macOS 用 `security` 的标准输入提示（约 128 字节上限，写完会读回核对）。Linux 用 `secret-tool` 的标准输入。Windows 用凭据管理器，删除走 `PasswordVault.Remove`。

不要把令牌、Cookie 写进聊天或命令行。

## 装 Skill

把 `skill/SKILL.md` 拷进你用的 AI 的 skills 目录（或按该产品的「自定义 Skill」方式导入）。这份说明只含流程，不含密钥。本仓库没有名为 `arena` 的 Cursor Skill；若你以前从旧压缩包装过一份，需要单独换成这一份。

更细的规则见 `docs/batch-upload.md`。
