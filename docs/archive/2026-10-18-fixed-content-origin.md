# 2026-10-18 · 固定作品内容域名 · wsnxxxs

- 负责人：wsnxxxs ｜ 执行：Codex desktop

## 本轮目标

减少访问作品及连续盲评时因新主机名产生的DNS查询，同时保留作品隔离、盲评匿名、实时访问门禁和现有基础设施。用户已明确授权提交、推送及上线。

## 改动

- 新增可选环境项 `CONTENT_PATH_ORIGIN`，必须是不与受信任站点共用主机名的HTTPS源（开发仅允许HTTP回环）。未设置时沿用原行为；本次生产候选值为现有 `https://w.arenaofbias.icu`，无需购买域名、证书、CDN或新服务器。
- 所有票据种类w/m/d/p/c可通过固定源 `/v/<key>/` 访问。外壳只运行哈希许可的可信代码，子页面位于 `/c/<key>/`，并同时受iframe及响应头CSP沙箱约束：不开放same-origin、顶层跳转和弹窗脱离沙箱。外壳校验子窗口身份及opaque origin，父消息必须来自实际父窗口和配置的站点源，原ready/fold/probe/camera协议保持。Gallery源码无需变化。
- HTML/CSS根引用、import map、DOM资源属性、fetch/XHR及两类Worker在交付层适配，保留原作文件。WebKit不透明源的模块Worker入口用普通Blob worker引导模块，保留顶层await与初始化消息顺序；Worker内部fetch/importScripts也按作品能力路径解析。
- localStorage/sessionStorage通过外壳按票据隔离，单作品序列化JSON上限65536字符、单key最多4096字符；浏览器存储禁用或额度不足时仅维持本页内存。没有模拟IndexedDB、ServiceWorker、SharedWorker，也不承诺完整等价于所有原生存储行为。
- 公共运行脚本带内容哈希，允许长期不可变缓存；它不含作品或用户数据。盲评/私有内容继续保留原访问门禁及no-store，撤回/过期作用于外壳和资源。作品资源只允许不带凭据的跨源读取及只读预检，主站API的来源检查不变。
- 可信外壳只计入文件读取限额，实际作品HTML才消耗页面预算，避免新结构将快速切换额度减半；新增边界回归；Nginx的页面限流映射同样排除外壳，保留通用文件预算。发布复核修复追加提交，不改写已推送main。
- 截图请求不再把整个固定内容主机视为一件作品，限制为当前外壳/作品能力路径及公共运行脚本；重定向逐跳检查仍保留。Show1兼容接口也使用新URL构造方法。Nginx两个前端的frame-src增加固定w域；旧通配域许可和旧地址继续保留。

- 本机语法135文件/0错，完整377/377通过；Mac临时路径按既有约定设 `TMPDIR=/private/tmp`，未更改既有路径断言。
- 现场server/admin基线加本轮增量补丁的Linux候选首轮及末次Worker内部资源补丁复验均语法135/0、376/376；补充页面预算回归后Linux最终377/377通过。实际输出保留在私有release证据中。
- 浏览器40个连续合成盲评页面：内容主机只有一个，隔离/加载检查0失败。这证明新票据不增加内容主机名，不等于测得权威DNS查询次数或公网长期性能分位数。
- 普通/模块Worker、顶层await期间立即发消息、Worker内部资源加载、根模块/CSS/图片及canvas读回、按作品存储隔离与刷新恢复通过。雪山原作及正式构建的台灯、多Worker古刹实际渲染；初次台灯源码入口只验证了布局，正式构建复验才确认渲染。
- 真实Gallery前端消费本地替换的只读公开目录：预览成功，合成盲评双栏就绪、投票按钮解锁、显示/收起控件消息链路通过，控制台无错误；没有向生产提交对局、投票、审核或账号操作。
- 生产入口只读静态信号检查覆盖1990件，77件命中localStorage、6件Worker、3件根fetch；没有命中IndexedDB/SharedWorker/ServiceWorker。8件大入口及外部JS未纳入信号检查，不把静态扫描称为全作品兼容证明。

## 发布与回滚

1. 核对公网/版本文件与既有基线、目标提交进入上游main，保留现场额外功能，仅增量安装已验证的运行文件及Nginx映射。
2. 备份运行文件、前端CSP配置、systemd设置和一致SQLite副本；本轮不迁移schema、不替换数据包、不重算或清空业务数据。
3. 先部署接收新路径的代码并补Nginx frame-src，通过独立Nginx语法检查；再启用 `CONTENT_PATH_ORIGIN` 并重启平台，使新签发URL使用固定主机。原来的 `CONTENT_ORIGIN_TEMPLATE` 保留。
4. 公网验证目录/预览新URL、旧URL、资源CORS与CSP、票据门禁、两个前端及截图服务状态。已有打开的旧对局和共享旧链接仍可能触发旧域名解析；站点API、验证码及作品第三方CDN仍有其固定域名。
5. 回滚时恢复备份代码/配置；如撤回路径实现，必须同时为已签发 `/v/<key>/...` 和 `/c/<key>/...` 加固定格式的临时跳转到原令牌域名，避免新共享链接失效。不要只删除环境项就声称新链接仍可使用。

## 明确没做

- 未把不可信HTML直接放到主站同源路径执行，未引入付费DNS/CDN套餐、外部代理或新的npm依赖。
- 未修改作品原件、数据包、计分规则、数据库schema或原有登录机制。
- 本文写于源码提交前；实际发布提交、备份、公网结果和回滚步骤见父级 `.local/content-path-validation/` 的私有release记录，不提前宣称上线。
